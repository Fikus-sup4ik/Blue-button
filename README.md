# Blue-button

Плагин для Lampa: действие **BLUE-BUTTON** на карточке запускает один поиск и выводит результаты подключённых адаптеров в общем списке.

## Статус

Версия: **0.1.5**. Плагин регистрирует ровно одно именованное действие контекстного меню `BLUE-BUTTON`, соответствующее контракту `Lampa.Manifest.plugins`; диагностика доступна через настройки. Bootstrap показывает этап, ошибку и stack trace; основной флаг готовности ставится только после успешной регистрации действия. Тест на настоящем устройстве Lampa и живом Lampac пока не выполнен.

## Установка

1. В Lampa откройте настройки плагинов и добавьте URL:
   `https://fikus-sup4ik.github.io/Blue-button/dist/blue-button.js`
2. В настройках Blue-button укажите URL своего сервера Lampac.
3. Откройте карточку фильма или сериала, затем context menu и выберите **BLUE-BUTTON**.

Файл доступен в репозитории: [dist/blue-button.js](dist/blue-button.js). URL установки нужно проверить на целевой Lampa до объявления рабочим.

## Сборка и тесты

```text
npm run build
npm test
```

В среде без npm можно выполнить `node scripts/build.js` и `node scripts/test.js`.

## Ограничения 0.1.2

Поддержан только Lampac и только provider entries с `method: "play"` и корректным `http(s)` URL. Методы `call`, `link`, RCH, сложная навигация серий и другие плагины не реализованы. Polling завершается по `ready` или ограничению 15 секунд/20 запросов; первый провайдер сам по себе polling не завершает. Форма HTML провайдера и запуск потока через Player должны быть проверены на вашей версии Lampa/Lampac.

Если bootstrap завершается ошибкой, `blue_button_ready` не устанавливается. На карточке доступно отдельное действие «Диагностика Blue-button»; пункт BLUE-BUTTON остаётся отдельным действием. Если Manifest недоступен, используется только документированный fallback бокового меню Lampa при наличии jQuery. Для очень старого WebView с отсутствующим Promise в сборку включён ES5 fallback.

## Основные цели

- Одна понятная кнопка поиска на карточке фильма или сериала.
- Параллельный поиск по источникам, для которых подтверждён программный интерфейс.
- Нормализация и объединение результатов.
- Удаление точных и вероятных дубликатов без потери вариантов озвучки и качества.
- Показ источника, озвучки, качества и типа результата.
- Передача выбранного потока штатному механизму воспроизведения Lampa.
- Диагностика ошибок и недоступных источников.

## Важное ограничение

Плагин может автоматически получать результаты только из источников, у которых есть доступный и разрешённый для использования API или документированный протокол. Закрытый плагин без такого интерфейса нельзя считать интегрированным только потому, что он установлен в Lampa.

## Разработка

Сначала изучаются реальные API и точки расширения Lampa, затем реализуются адаптеры и пользовательский интерфейс. Каждая функция должна иметь проверку; неподтверждённые возможности нельзя объявлять готовыми.
